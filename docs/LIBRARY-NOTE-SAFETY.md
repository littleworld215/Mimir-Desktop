# 文献笔记与标签：保存及离开保护

## 使用方法

展开文献卡片后，可以分别编辑标签或整段自由笔记。保存失败会在卡片内显示原因并保留输入，重试成功后才结束对应编辑；保存笔记不会清掉尚未保存的标签。保存期间禁用输入、取消和重复提交。

离开模块、切换项目、打开阅读器、移除文献，以及解除当前筛选项目的关联时，未保存的笔记和标签会进入已有“留在这里／丢弃后离开／保存后离开”流程。保存失败会留在原处；同一卡片同时编辑笔记与标签时，“保存后离开”将二者合并为一次更新。

阅读器中的“添加”会沿用原有规则追加带时间戳的笔记。追加失败不清空输入，也不会把失败内容显示为已保存。关闭或切换侧栏同样检查未保存内容；保存中不能通过关闭或 Esc 绕过请求。

## 已保存数据与显示

更新成功后使用后端确认的文献更新卡片与阅读器，避免为了刷新列表而卸载其它编辑器。“保存后打开”根据文献标识重新读取最新已确认数据，不使用点击时的旧快照，随后追加不会覆盖刚刚保存的内容。

自由笔记前缀和时间戳记录中的全部段落都会显示。显示解析只派生阅读视图，不改写历史存储；复制、备份及其它模块使用的原始笔记保持原样。
