# 备份范围说明与注册快照保护

G-07保留归档格式1，新增可选metadata版本1。它用于说明备份实际保存的内容及已知未纳入项，不证明全部科研资料都已备份，也不是数字签名。

## 如何使用

1. 保存工作后，从设置的“备份与恢复”进入离线维护窗口。
2. 选择要备份的科研空间执行备份；归档保存在受管备份目录中。通过自检检查现有归档，分别查看“范围说明”和“内容校验”状态。
3. 对候选归档点击“展开范围说明”，按页检查超限排除项和已识别外部引用。默认摘要不显示外部目标，每页最多100项。
4. 恢复时通过原生窗口选择实际归档和新目录。范围确认默认取消；可查看说明后返回，再明确选择继续恢复。
5. 恢复仍创建新空间，不覆盖原空间。若目录已发布但登记失败，保留目录，按维护记录重试登记，不重复生成另一个空间。

例如，空间内存在一个超过当前单文件限制的资料和一个外置PDF引用时，范围分别显示排除数量与外部引用数量。外置引用仅登记，未自动读取或打包；验包通过也不会将它改为已纳入。

## 包内记录与兼容

- 来源记录实际应用版本及平台；缺省版本显示未知，不从Git提交猜测安装版本。
- 数据库版本来自一致快照的实际`PRAGMA user_version`。声明不能替代恢复时的数据库、外键及历史文件检查。
- 默认单文件1GiB、清单整体64MiB、最多10万条目、展开1TiB；元信息及排除/外部记录同样受限。
- 外部识别仅检查五类已知结构化路径字段，不扫描聊天、Wiki等自由正文，不打开或探测引用目标。空间JSON缺失、损坏、超过64MiB或引用不可解释时明确标记识别范围未知。
- 旧格式1没有metadata仍可读取与恢复，但范围未知；已经声明却损坏的说明或较新metadata版本会被拒绝，不能降级为旧包。
- 刷新候选列表后旧标识失效；文件、父目录或确认期间身份变化会阻止继续。没有内容验包时，详情只标记“未校验”。

## 本机注册快照

登记前，将原本机注册文件的原始字节保存到`<用户目录>/.mimir/restore-registry-snapshots/`。该文件可能包含凭据，不应作为普通资料分享。

Windows下，先为新目录建立并回读受保护DACL，只允许当前用户SID，拒绝Network SID，再写快照；文件同步、实际关闭及权限/内容复核后才准备登记。同一次登记的原生ACL操作共享10秒预算。发布后的验证失败如实报告，不假装登记回滚。

既有目录权限不合格时拒绝登记，不自动修复；旧平铺快照保留原位，不修改权限或纳入普通保留清理。首次创建目录的保护失败时，仅在身份未变且仍为空的情况下非递归清理本次目录，以便重试。任何既有或非空资料均保留。

只读自检不会创建目录、修改ACL或删除历史快照。没有新旧快照时报告“不适用”；旧快照报告保护未知。大量文件超出检查预算时报告未检查数量，不视作全部通过。
