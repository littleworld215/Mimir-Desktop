# 资产文件健康检查

在资产库选择“文件健康检查”，再点击“开始检查”。它检查当前科研空间的文件资产及全部历史版本，包含归档资产；不会扫描未被版本记录引用的额外目录，也不检查外链。

## 结果含义

- **可打开（内容未校验）**：文件可按只读方式打开，打开前后的文件与目录身份检查通过。它不证明文件内容完整，摘要基准仍是“未建立”。
- **文件缺失、不可打开、不是普通文件**：对应版本目前无法按普通文件读取入口打开；报告不会自动修复或删除资料。
- **路径非法或链接不安全、文件归属不符**：检查拒绝了不满足受管路径规则的记录，不会因此扩大文件读取范围。
- **检查期间文件变化**：打开前后的身份或元数据不一致，应在资料操作结束后重检。
- **尚无文件版本**：文件资产没有可检查的历史文件引用。

## 进度、停止与边界

每批最多50条版本记录。四路调度在每批内最多同时检查4个文件；每个文件仍分别执行完整路径、归属、祖先目录和文件身份检查，不缓存检查结论，不读取正文。结果按资产和版本原顺序展示。

“最近一批”仅展示最近返回的最多50条；“问题列表”最多保留前500条问题，汇总继续计数。关闭报告后清空，不写入数据库或记录为最近使用。

点击取消或关闭后停止后续批次；已发出的当前批次可能继续收尾，迟到结果不会加入报告。空间切换拒绝旧结果，并等待已启动检查结束。关闭失败必须使整批失败，不能降为普通空间中止。

这是在线检查时点结果。检查期间导入、删除或编辑资料可能影响覆盖范围；需要时重新检查。数据库结构、外键和完整读取请进入“备份与恢复”的离线维护自检。
