# 文献日期

文献卡片分别显示 arXiv 初始提交、版本更新、来源出版日期和入库时间。鼠标停留在来源日期上可看原始值和来源；仅年份明确标注，不补成一月一日。

- 入库时间只代表首次保存，重复导入不改变它。
- arXiv Atom 的 published / updated 分别保存；OpenAlex、Semantic Scholar 的日期保存为来源出版日期，不保证等于最终期刊正式出版。
- 来源未注明的兼容调用只记录未知来源出版日期，不根据标识猜成 arXiv 提交日期。
- 旧记录缺少来源日期时显示未知；不联网回填，也不以入库时间推断。
- 显式重新导入可补充来源日期；空值、非法日期及更粗精度不擦除已有精确日期。用户笔记、标签、PDF路径和原入库时间保留。
- BibTeX 年份优先取来源出版年份，其次 arXiv 初始提交年份；两者缺失时不填 year。原来已写入的 BibTeX 文件不自动重写。

日期作为可选 dates 元信息保存在科研空间 .mimir/store.json 的 library:papers 原记录内，值、精度及来源一同保存；整空间备份按原 JSON 保留。无需数据库迁移。

开发验证与日常安装版更新分开记录。自动检查使用合成资料，不意味着真实来源元数据一定正确；用户仍须核对论文原文及正式出版页。
