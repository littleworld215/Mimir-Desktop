# 科研计划：使用与验收指引

本指南用于已批准的I10整合。先使用合成资料和独立测试空间；源码构建、目录包、日常安装及真人验收分别登记。真实课题尚未指定，不自动导入文献或调用模型。

## 日常操作示例

1. 侧栏→科研计划→方向，创建一个主方向；新建科研项目，选纵向/横向/其他及方向。
2. 为项目添加待办，分别设置截止日期和“我的一天”。截止日期不会自动加入我的一天。周期待办设置截止日和日/周/月间隔，完成后一次生成下一期；撤销再完成不重复生成。
3. 科研计划→日程，切换周网格、周列表或月历，选择日期新增全天或起止时间日程。总览摘要可返回相应列表。
4. 记录可添加文本字段及Markdown正文。原文/阅读/分栏只改变阅读方式；预览不执行HTML、不加载远程图片。搜索覆盖标题、正文和字段，可叠加类型、分组、项目、状态及归档筛选。
5. 编辑停顿约500ms保存恢复草稿，尚未正式保存的提示仍保留。“保留草稿并返回”成功后可以离开，重新启动从恢复草稿核对并继续；正式保存成功才清理本次草稿。
6. 文献计划可选择当前文献库条目；正常文献字典与已有数组均只读投影名称和标识。打开关联文献/文献项目/实验返回原模块；失联可见，不跨模块删除。
7. 导入与导出→选择Research-Workbench JSON v1/v2或本项目JSON→核对分组与重复策略→预览→确认。默认跳过重复；外部设置不改变托盘、自启、提醒或模型。JSON导出包含归档/回收站；草稿和提醒状态使用整空间备份。

## Windows后台偏好（默认全部关闭）

设置→科研计划→分别勾选→点击“保存科研计划后台偏好”。本区域单独保存，不以页面底部的通用设置按钮替代。失败保留输入，离开会检查未保存状态。

- **运行期间提醒**：只检查当前空间的未完成到期/逾期待办，包括自定义待办类型。启动、切换空间及每15分钟检查；每轮最多5条成功通知，积压留待后续轮次。按记录和截止日持久去重，系统勿扰可能隐藏通知；系统接口返回show不证明人已读到。
- **托盘驻留**：关闭按钮隐藏窗口并保留工作，点击托盘或再次打开本应用可重显。托盘明确“退出”仍检查未保存输入并等待任务结束。进入备份维护同样会关闭窗口和排空，不因驻留而隐藏维护请求。
- **开机启动**：只在安装包中可设置。显式保存后核对本安装的系统状态；更换安装位置后可重新应用。读取设置、正常启动或导入均不修改系统启动项。普通退出后没有独立提醒服务。

## 整空间恢复示例

1. 保存编辑，设置→科研空间→备份与恢复→确认关闭工作台；处理未保存提示，等待任务结束。
2. 在维护窗口选择合成科研空间创建完整备份，再运行只读自检。报告分别列出正式计划、草稿、提醒及失联数量，不展示正文或私密路径。
3. 选择备份，使用新的空间名称及不存在的目标目录恢复。原空间保留，登记只追加新UUID，原激活/default指针保持。
4. 恢复保留计划JSON、草稿和提醒状态的原字节；宿主文献关联使用稳定标识，无需全文替换正文路径。旧备份没有计划模块仍可恢复；坏文件、非法UTF-8和较新格式在发布前阻断，不重置为空库。
5. 失联引用和孤立草稿保留并警告，不能把“ZIP摘要一致”当作“所有引用均可用”。如自检发现异常，保留原包并使用兼容版本检查，不直接修改真实库。
