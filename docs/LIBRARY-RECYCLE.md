# 文献回收站

## 移除与恢复

1. 在文献卡片选择“从文献库移除”。有未保存笔记或标签时，先处理原有保存/放弃选择。
2. 阅读关联影响预览。它包含历史证据版本、研究问题、写作素材包、科研计划和计划恢复草稿的引用数量；归档与旧版本也计入。
3. 确认后，文献从活动列表、Agent检索、计划关联候选和新组会材料中隐藏。原标识、笔记、标签、日期、PDF路径、评分及证据/素材历史保留。
4. 通过文献库顶栏“文献回收站”检索标题或标识，选择“恢复”，再次查看影响后确认。恢复沿用原标识，已有引用可重新解析。

不提供永久清空、自动保留期限或自动回收文件。重新导入已回收的同标识会明确拒绝；先显式恢复，再按需重新导入。此前旧版本已经永久删除的文献不能由本入口找回。

## 失败与关联

- 保存失败留在确认窗口，可重试或取消。执行前会核对空间代际、文献和关联指纹；五分钟后或内容有变化须重新预览。重复点击不会重复执行。
- PDF下载实际结束前阻止回收，避免晚到任务覆盖已回收资料。失败不提前释放下载寿命。
- 历史引用保留原快照；回收期间会显示来源已移除/失联，不冒充可用来源。原项目已删除时保留旧关联标识，并在恢复预览中提示，不重建项目。
- 历史证据/研究/计划文件损坏时，不以“零关联”继续回收；先检查文件或备份。
- 新固定接口只接受可信工作台主窗口主框架、当前空间和主进程生成的预览令牌。旧的直接移除接口返回操作指引，不能绕过确认。

## 存储与备份

使用原 library:papers 记录的可选 removedAt 标记；无需迁移数据库，不改变已有标识。空间 JSON 保存失败时还原缓存；文献更新先复制后发布。

整空间备份包括回收记录和原文件。恢复在新目录中重映射回收记录的PDF路径，保持笔记及历史原文；原空间不变。新增只读自检报告活动/回收数量，损坏日期或回收元信息阻止恢复发布。旧记录没有这些可选字段仍合法。

开发验证、目录包和日常安装更新分别记录。本轮不调用模型、不修改真实文献；I5/I6原待验不因此完成。
