# 文献恢复草稿安装与回退（2026-10-23）

当前日常产品为 `6645129b2ff9e6162236ef8021f179f2a628c247`。新版在独立目录部署，桌面与开始菜单均已切换，Windows Shell正常启动并复用同主实例。旧276aba3及更旧安装保留；源码交付、安装验证和用户真实使用验收分别记录。

## 使用入口

从桌面或开始菜单“Mimir 科研工作台”进入文献库，先核对当前科研空间。

- “库内检索”只查询本机保存的标题、作者、标识、摘要、笔记和标签，可与项目筛选组合。上方arXiv/Web为外部搜索；网页多候选须选择并确认，取消不会写入首条。
- 编辑卡片笔记、标签或阅读器追加，暂停输入约500毫秒后触发暂存。看到“恢复草稿已暂存（尚未正式保存文献）”才表示本次输入已确认落盘；点击“保存”才更新正式文献。
- 意外退出后，在同一空间点击“恢复草稿”，先对照基线、当前文献和原始输入，明确恢复到编辑器，再正式保存。已有内容冲突时不强制覆盖；已回收或失联文献的草稿仍可查看和复制。详见[恢复草稿](LIBRARY-RECOVERY-DRAFTS.md)。
- 正常离开仍须保存或明确丢弃，未确认落盘的字符不保证恢复。不要为试用而强制结束日常程序。
- 日期保留初始提交、版本更新、来源出版与入库语义；未知不猜填。[日期说明](LIBRARY-DATES.md)。
- “文献回收站”支持影响预览与恢复，保留PDF、笔记和历史，重新导入不会自动恢复。[回收站说明](LIBRARY-RECYCLE.md)。

## 回退

先保存输入并正常退出新版，确认实例已停止。保留的旧版为 `%LOCALAPPDATA%/Programs/Mimir-Research-Releases/20261022-library-276aba3-01/Mimir.exe`；两份旧快捷方式在本次保护目录中。旧版不提供本轮新增的编辑恢复界面，切回旧程序不等于恢复数据。

如果升级后已有业务变更，先新增备份，再在维护界面将旧归档恢复为新空间；不要覆盖当前空间、原配置或重新放回原残留锁。入口切换失败时有恢复旧快捷方式的保护分支，但本轮未故障注入验证该分支。
