# 恢复后的路径、论文快照与模板关联（G-04）

2026-10-24。承接[I6交付](I6-DELIVERY.md)、[资产库兼容](I6-ASSETS-RESTORE.md)及来源[G-04判据](https://github.com/littleworld215/research-asset-library/blob/main/docs/I6-ACCEPTANCE-MATRIX.md)。只增强新空间恢复，不改变日常安装或原科研空间。

## 哪些内容会改写

恢复为新空间时，新UUID在验证阶段生成一次，关联与登记使用同一个值，原active/default指针不变。只将以下已核对结构中落在旧空间根内的绝对路径映射至新根：

- 文献 `library:papers.<记录>.pdfPath`，兼容旧数组形态。
- 科研项目 `library:projects.<记录>.paperDir`。
- 论文最近项目 `paper.recentProjects[].dir`。
- 聊天消息的 `messages[].artifacts[].path` 和执行步骤的 `messages[].run.steps[].artifacts[]`。

匹配按目录边界，空间外、URL及相对值保留；未知嵌套同名字段不猜改。聊天正文、工具摘要、命令、Wiki、LaTeX、插件文本、审计与资产版本正文保持原样。原JSON自有键包括 `__proto__` 也保留，不转成对象原型。没有可靠旧根的早期包不猜测路径。

## 快照与模板

论文快照以**原始项目目录字符串**的SHA1前16位作为桶键。恢复只将已确认空间内项目的旧桶改名至新项目路径对应的键；Windows按文件系统大小写语义检查。所有目标占用和多源汇聚冲突先检查，拒绝合并或覆盖。未知桶和外部项目桶原样保留，分别计数提示；空间外项目资料不会因此被选入备份。控制父目录和桶链接拒绝，不能借junction写出暂存根。

任务包模板保存于空间内 `assets-task-pack:<空间ID>`。新备份增加可选 `sourceSpaceId`，格式仍为1，旧调用和旧包可缺省。恢复把已确认来源模板复制到新UUID键，保留旧键和额外历史模板；新键冲突拒绝。没有来源ID的旧包仅在模板键唯一时兼容推定，多键歧义拒绝，不静默选择或合并。可用原空间重新生成包含来源ID的新备份；原空间不可用时保留原包与冲突信息，另行确认来源，不能猜改原包。

界面仅显示关联快照、未知快照、外部项目快照、模板与未关联模板数量，不传旧路径、未知名称或模板正文。新增外部桶计数可选，旧四字段结果仍能显示。
