# 文献导入、库内检索与项目保存

当前安装更新（2026-10-22）：产品276aba3已包含本页功能及后续日期、回收站和笔记保存保护，见[使用与回退](LIBRARY-DEPLOYMENT.md)。本页2026-10-21测试数字保留当时快照，不是当前全部功能的计数。

## 库内检索（离线）

文献列表上方的“库内检索”只筛选本机已经加载的文献，不发起联网搜索，也不更改上方 arXiv/Web 搜索框。支持标题、作者、标识、摘要、已保存笔记及标签；空格分隔的多个关键词须同时命中，可以跨字段匹配。不区分英文大小写，兼容全角字母。项目与关键词可以组合，清除后恢复该项目原有列表及排序。

结果数单独显示，项目总数不受关键词影响。没有匹配时提供明确空态；临时关键词过滤只隐藏卡片，清除后保留卡片内尚未保存的笔记/标签。该保证针对关键词过滤，不代表已补齐旧有所有模块离开或保存失败保护。

该入口按当前加载文本筛选，没有新增数据库索引、联网请求或持久化字段；不是大库分页/虚拟滚动方案，尚无大规模性能结论。

第二批最终验证（2026-10-21）：本地十项专项及前批十六项共二十六项通过；复核后完整类型/原始全量/生产构建均exit 0，238文件通过/4既有跳过（242），2103项通过/9既有跳过（2112）。开发Electron `07`/`48`/`49` 共10/10零重试，包含真实编辑草稿→零匹配→清除→保留草稿；深浅主题800宽截图已查看。静态复查与运行自验分别记录，不等于独立运行QA或安装更新。

## 网页导入

在文献库切换到 Web 搜索后，点击结果的“按标题查找论文候选并核对”。应用查找最多五条学术候选，展示原网页及候选的标题、作者、标识、来源、日期、链接和摘要。

候选默认不选中。核对后选择一条，再点击“确认导入”；取消不会写入文献库。检索排名不代表同一篇论文，也不代表已经核对。实际检索可能返回 OpenAlex、Semantic Scholar 或 arXiv 来源，以返回字段和链接为准。

导入失败会保留候选与选择，便于重试；处理中禁止重复确认或关闭。切换项目、科研空间或离开模块后，迟到的候选请求失效。关闭后恢复原入口焦点。原有直接导入学术搜索结果的操作继续可用。

本次没有新增网页素材导入或网页溯源持久化字段；原网页保留在核对窗口中，正式文献仍按所选候选的标识保存。不会自动判断两篇论文相同，也不调用模型。

## 新建和重命名项目

只有后端明确保存成功，编辑器才结束。失败、异常或取消未保存内容的离开操作时保留标题；保存期间锁定输入与重复提交。保存已成功但列表刷新失败，会明确提示“已创建／已重命名”，避免将刷新错误当作保存失败重复创建。
