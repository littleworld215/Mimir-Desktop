# 科研阅读、证据与素材使用指引

本轮能力帮助完成“阅读—笔记—证据—比较—问题—固定版本素材—导出—重启找回”。全部为人工科研辅助，不自动生成实验结论、不调用模型，也不会自动导入真实文献。源码、候选包、日常安装和真实课题验收分别记录，最终状态见[逐批验证报告](https://github.com/littleworld215/research-asset-library/blob/main/docs/verification-research-workflow-20261030.md)。

## 1. 返回上次浏览位置

在文献库选择项目、输入关键词，进入证据矩阵或研究问题后，模块往返和重启会尝试恢复有效的筛选、列表位置及详情。失效项目有提示，不会暗中恢复已回收条目；用户的新操作优先于迟到的恢复响应。已有未保存保护继续生效。

偏好仅保存在这台电脑的当前科研空间，最多64KiB、最近20篇阅读位置，不含笔记或证据正文、不随整空间业务备份同步。“清除本机浏览位置”只清偏好。原阅读器无法可靠取得真实当前页，不会把请求定位页冒充已读页；增强模式只在实际渲染完成后记录物理页。

## 2. 阅读 PDF 并摘录

1. 打开文献的阅读窗口。默认使用原阅读器；已登记本地PDF且空间就绪时，可主动点“增强阅读”。
2. 增强模式每次显示一页，可输入物理页码、翻页或缩放。物理页不是论文印刷页标签；扫描页明确提示没有文字层，不自动OCR。
3. 在当前页文字中拖选，点“摘录为证据”。跨侧栏、旧页或旧空间的选区会被拒绝；超出20000码点时提示缩小范围，不截断。文字层顺序可能与视觉阅读不同，接收前请检查。
4. 原文与当前物理页进入未保存新卡，只有当前项目关联；不会复制别卡的核对状态或文档绑定。已有编辑时可留在原处，原输入与待接收摘录同时保留，也可显式保存或丢弃后接收。
5. 填写研究问题等字段，点“保存证据”才入库。保存失败或冲突保留输入；保存后的证据仍未核对，须由你检查原文和页码后再显式核对。

增强模式限制实际PDF字节不超过128MiB、单页Canvas不超过1600万像素，只读取现有受管PDF；不执行PDF脚本、表单或外链。缺失、损坏、加密、超限或加载失败时可重试或返回原阅读，当前输入保留。未保存新证据和摘录候选不承诺跨崩溃恢复。

如果证据来源改为另一篇文献，“打开原文”继续用原阅读器查看该来源，增强摘录暂不可用。点“返回当前文献PDF”后才可为当前文献摘录，避免把另一篇的正文或页码归入当前文献。

## 3. T2I 公平性填写框架

证据编辑器默认为“通用”。选择“T2I公平性”只改变提示，不改已有输入或标记来源事实。提示覆盖公平性定义、模型与提示条件、交叉群体、数据与样本、指标和不确定性、识别器依赖及文化/语言局限。

“预览空白填写提纲”列出将变化的字段；“取消插入”不改内容，“仅插入空字段”只填研究问题、方法、数据或材料、主要发现、局限、个人评注中的空字符串。空格也算已有输入；原文、项目、定位和判断关系保持。提纲没有虚构模型、数值或结论，仍需人工填写并显式保存。

正文编辑中的Ctrl/Cmd+Enter沿用保存快捷键；提纲预览须通过其明确按钮操作，不能借预览触发证据保存。预览取消后焦点返回入口。

## 4. 从比较到固定素材

在证据比较矩阵组合筛选，在“研究问题与写作素材”创建问题组并选入已有证据，再从问题组构建写作素材包。素材引用固定的证据版本；后续证据修订不改写旧素材。需要更新引用时使用原有差异预览与显式更新，导出前检查所用版本。

Markdown导出使用原生保存窗口并保存为新文件。取消不写入；关闭后重启可从有效浏览上下文找回。笔记原文、证据历史与素材历史仍走现有存储和整空间备份，和本机浏览偏好不同。

## 5. 常用标签

在资产库展开“管理常用标签”，选择现有标签并“添加常用标签”。快捷按钮可用键盘操作，最多20个，偏好仅本机/当前科研空间保存。

- 点击沿用原“包含标签”动作；不自动删除排除项、改匹配方式或覆盖已保存筛选。相互冲突条件仍按既有规则处理。
- 重命名显示最新名称；删除后显示“已失效标签 #ID”，不会按同名重建，须显式取消常用。
- 存储或格式读取失败会提示，原偏好与当前筛选保留；较新或损坏偏好不自动重置，可重试读取。
- 空间切换不沿用旧偏好或旧异步提示，不改变资产数据库。

## 6. 导入和扫描量测

新增入口仅显式运行，普通回归不自动执行。四档合成数据为100/1000/5000条×4KiB，以及100条×1MiB；每档一次预热、五次独立库/目录样本。JSON只测试文本导入，文件扫描另生成普通文件，健康检查每资产两历史版本。不做5000×1MiB组合。

在目标仓库用Node22、pnpm及已准备的双ABI环境，设置`MIMIR_IMPORT_SCAN_REPORT`为**全新且不存在的报告文件**，两个入口各用不同文件，依次运行：

```text
pnpm exec vitest run --config vitest.benchmarks.config.ts --poolOptions.forks.maxForks=1 --no-file-parallelism
pnpm exec playwright test --config playwright.benchmarks.config.ts --workers=1 --retries=0
```

开始前要求至少2GiB可用磁盘；夹具均在新临时空间，正常日常程序不强制退出。报告保留样本、min/median/max、环境、实际JSON字节和内存口径；不足20样本不报P95。原始报告和具体限制见[量测报告](https://github.com/littleworld215/research-asset-library/blob/main/docs/verification-research-import-scan-20261030.md)。

同步JSON提交与目录扫描不能承诺中途取消；文件队列停止后仍须等待当前文件真正结束。在线健康检查只停止后续批次，当前批完成与句柄释放另计。健康“可打开”不等于内容完整，摘要基准未建立。本轮未修改生产安全检查或宣称已提速。

## 7. 交付与待验

新目录包用于隔离合成验收，不覆盖旧安装、原配置、快捷方式或真实科研空间。日常更新仍需正常保存退出、先备份、独立目录部署和可回退入口。

本轮不代替I5真实模型/跨机器、I6其余异常矩阵、I10系统通知/自启、macOS或真实T2I课题试用。新上下文静态复核、自动运行与用户真实使用分别登记，不能互相代替。
